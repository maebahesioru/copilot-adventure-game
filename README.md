# Adventure Game (built with GitHub Copilot)

A small command-line "choose your own adventure" game in Python, generated with the help of **GitHub Copilot Chat** during MLH Global Hack Week: Hacktoberfest.

## Theme
You are a stranded engineer aboard the abandoned Mergington Station. Explore the derelict station, find an energy cell, and escape via an escape pod.

## Features
- 8+ scenes / rooms with multiple choices
- Two endings (escape = win, stranded = lose)
- An inventory item (the energy cell) that affects the story
- Input validation and replay support
- Standard library only (no external dependencies)

## How to run
```
python3 adventure.py
```

## How it was made
I described the game to GitHub Copilot Chat and iterated on the generated code. Copilot also helped me with other Global Hack Week challenges this week (bug fixing, adding features, and writing tests).
